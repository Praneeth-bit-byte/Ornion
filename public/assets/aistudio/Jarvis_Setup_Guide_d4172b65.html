⚡ ORNION — PERSONAL AI ASSISTANT

ORNION — Installation and User Guide · Created and developed by Praneeth Thota

ORNION Neural Interface
What is ORNION? A voice-and-text-controlled Personal AI Assistant and Automation Platform created and developed by Praneeth Thota. Features desktop application launching, YouTube & Google search automation, WhatsApp Web message drafting, unread email briefings, real-time stock market technical analysis (SMA Buy/Sell signals), and the 3D ORNION Neural Interface HUD.

1. Prerequisites

  • Operating System: Windows 10/11 (Primary Development Environment), macOS, or Linux.
  • Python: Python 3.10 or newer (download from python.org).
  • Optional Groq API Key: Free cloud LLM API key from console.groq.com/keys.

2. Step-by-Step Installation

1 Prepare the Project Folder: Open the ORNION project directory on your computer.
2 Run the Automated Setup Script ("ORNION Setup"):

On Windows: Double-click install.bat or run in Command Prompt:

install.bat

On macOS / Linux: Open your Terminal in the project folder and run:

chmod +x install.sh
./install.sh
3 Configure Your Groq API Key (Optional): When prompted in the terminal, paste your key from Groq Console (saved to ~/.ornion/free.key). If you skip, ORNION still executes local deterministic commands.
4 Launch ORNION & Neural Interface HUD: Start ORNION at any time: 
python jarvis_voice.py
Then open http://127.0.0.1:8765 in your browser to view the ORNION Neural Interface.

3. Key Features & Voice Commands

Voice / Text Command Feature & Execution
"Ornion, open VS Code" App Launcher: Launches VS Code, Chrome, Notepad, Calculator, or installed desktop apps.
"Play lofi on YouTube" YouTube Automation: Opens YouTube search in your default browser.
"Stock market report" Live Market Intelligence: Connects to Yahoo Finance and checks Nifty 50, Sensex, Reliance, Nvidia & Bitcoin.
"Should I buy Reliance?" Technical Buy/Sell Analysis: Calculates 5-period and 15-period moving averages & momentum to issue a BUY, SELL, or HOLD signal.
"Send WhatsApp to Pallavi saying hello" WhatsApp Web Automation: Opens WhatsApp Web with your drafted message pre-filled.
"Check my unread emails" Inbox Briefing: Summarizes cached priority emails into a spoken update.
"Volume up" / "Mute" System Audio Controls: Adjusts audio volume or mutes system audio.

4. Hybrid Cloud + Local Cooldown Fallback

When cloud LLM tokens hit a rate limit (HTTP 429):

  • ORNION parses the exact cooldown seconds from the rate-limit response.
  • During cooldown, ORNION routes deterministic commands (apps, time/date, volume, WhatsApp URL, YouTube URL, stock chart checks) to local Python execution.

5. ORNION Neural Interface HUD

Open http://127.0.0.1:8765 (or jarvis_workplace.html) in your browser to view:

  • Rotating wireframe 3D globe and segmented reactor rings.
  • Real-time responsive voice frequency oscilloscope.
  • Live stock market ticker panel with sparklines and Buy/Sell/Hold indicators.
